Key points

What this project covers and found, in brief.

  • Reads a game's numbers and tooltips from screen frames, for a planned reinforcement-learning agent.
  • Uses RapidOCR plus a small vision-language model (Qwen2.5-VL-3B).
  • Read 77 of 78 labelled items exactly, against 21 of 78 for the original stack on the same set.
  • A separate scanned-card comparison raised character accuracy from 31.8% to 90.7%. The RL part never started.

Limits

  • One game profile and 13 frames
  • Exact match only: no character error rate; latency logged but never summarised
  • The one miss is a small '4' glyph the detector skips
  • The reinforcement-learning part of GameRL was planned and never started

Outcome: Succeeded. Goal: read the game's numbers and tooltips reliably. 77 of 78 labelled items were read exactly, against 21 of 78 for the original stack. The reinforcement-learning part never started.
